# Macbook Pro Landing Page

A visually stunning and interactive landing page for the MacBook Pro, built with modern web technologies. It features a 3D model of the MacBook, smooth animations, and a clean, responsive design.

## Features

- **Hero Section:** An engaging introduction with a captivating video background.
- **Product Viewer:** An interactive 3D model of the MacBook Pro, allowing users to view it from different angles and in different colors.
- **Showcase:** Highlights the key features of the MacBook Pro with seamless video transitions.
- **Performance:** A section dedicated to showcasing the performance of the MacBook Pro.
- **Animated Features:** Smoothly animated feature highlights that trigger on scroll.
- **Highlights:** A section for other notable highlights of the product.
- **Responsive Design:** The landing page is fully responsive and looks great on all devices.

## Technologies Used

- **React:** A JavaScript library for building user interfaces.
- **Vite:** A fast build tool and development server for modern web projects.
- **GSAP (GreenSock Animation Platform):** A powerful JavaScript library for creating high-performance animations.
- **Three.js:** A 3D graphics library for creating and displaying 3D computer graphics in a web browser.
- **React Three Fiber:** A React renderer for Three.js.
- **Tailwind CSS:** A utility-first CSS framework for rapid UI development.
- **Zustand:** A small, fast, and scalable state-management solution for React.
